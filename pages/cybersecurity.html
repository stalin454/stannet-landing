DOCKER / FASE PREPARADA

Laboratorios reproducibles, seguros y locales.

Desde el principio queda definida la ruta Docker: servicios vulnerables controlados, SIEM local y ejercicios de hardening. El primer bloque publica la guia; los contenedores se activaran en la siguiente entrega para evitar laboratorios inseguros o incompletos.

cd stannet-cyber-labs
docker compose up --build
