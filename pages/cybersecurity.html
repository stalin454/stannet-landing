TEORIA Y METODO

Primero entiendes. Luego practicas.

Esta seccion recupera la base teorica y el metodo de aprendizaje: conceptos, ejemplos, practica guiada, autoevaluacion y entrega documentada.

BASE 01

Seguridad digital

Activo, amenaza, vulnerabilidad, riesgo, confidencialidad, integridad y disponibilidad. Antes de actuar, separa hechos, hipotesis y decisiones.

Entrega:

Tabla de cinco activos, amenaza asociada, control recomendado y evidencia necesaria para comprobarlo.

BASE 02

Redes para analistas

IP, puertos, DNS, TCP, TLS, HTTP y rutas. El objetivo es explicar como viaja una peticion y que puede observar un analista.

Entrega:

Diagrama navegador, DNS, servidor, protocolo, puerto y campos que usarias en una investigacion.

BASE 03

Linux y permisos

Rutas, usuarios, grupos, procesos, servicios y permisos. Minimo privilegio antes que soluciones rapidas como permisos excesivos.

Entrega:

README de laboratorio con comandos, resultado, cambio de permisos y explicacion del riesgo evitado.

BASE 04

Logs y cronologia

Un log registra eventos, no conclusiones. Revisa fuente, zona horaria, cuenta, origen, resultado y actividad posterior.

Entrega:

Informe con resumen, alcance, evidencia, cronologia, hipotesis, limitaciones y siguiente paso.

METODO

Ciclo de aprendizaje

Concepto, ejemplo, practica, evidencia, autoevaluacion y write-up. Cada unidad debe terminar con algo que puedas explicar en una entrevista.

Ritmo:

60 minutos de teoria, 60 de practica, 45 de documentacion y 15 de repaso tecnico en ingles.

SOC

Triage profesional

La severidad inicial no es veredicto. Investiga criticidad del activo, evidencia, alcance, contexto y urgencia antes de cerrar o escalar.

Decision:

Investigar, cerrar con evidencia o escalar segun playbook, siempre indicando que falta confirmar.

RED

ACL y firewalls

En reglas secuenciales gana la primera coincidencia. Una regla amplia al principio puede romper una politica aparentemente correcta.

Practica:

Evalua flujos permitidos y prohibidos, documentando regla coincidente, resultado y politica alternativa.

CLOUD

Responsabilidad compartida

El proveedor protege parte de la plataforma; tu configuracion, identidades, datos y permisos siguen necesitando control.

Practica:

Simula una matriz IAM, detecta permisos excesivos y escribe una propuesta de minimo privilegio.

PORTFOLIO

Cuaderno exportable

Tu evidencia debe demostrar proceso: objetivo, entorno, alcance autorizado, procedimiento, resultado, limitaciones y aprendizaje.

Publicacion:

Anonimiza datos, elimina secretos y prepara un resumen ejecutivo en ingles tecnico.

DOCKER / BLOQUE 2 ACTIVO

Primer laboratorio reproducible, seguro y local.

El paquete descargable incluye una web vulnerable de entrenamiento, logs generados y plantilla de informe. Sirve para practicar pentesting web basico, analisis SOC y documentacion profesional con alcance controlado.

cd stannet-cyber-labs
unzip stannet-cyber-lab-block-2.zip
cd stannet-cyber-lab
docker compose up --build
