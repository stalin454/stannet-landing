# Roadmap

Fase 0: UX pública, búsqueda flexible, responsive, CI/CD, arquitectura y threat model.

Fase 1 Identity: API versionada, base de datos, migraciones, registro, verificación de correo, login/logout, sesiones seguras, recuperación, roles, rate limiting y tests.

Fase 2 Marketplace: perfiles, catálogo dinámico, solicitud multi-step, matching, propuestas, máquinas de estados, paneles y auditoría.

Fase 3 Comunicación: conversaciones autorizadas, mensajes persistentes, leídos/no leídos, bloqueo/reporte, notificaciones y realtime.

Fase 4 Confianza: valoraciones ligadas a trabajos completados, moderación, archivos seguros, privacidad/exportación/borrado.

Fase 5 Comercial: entitlements, pagos, webhooks verificados e idempotentes y facturación según el modelo legal definido. El core no se acopla a un precio fijo.

Fase 6 Mercado y grado: PWA, rendimiento, SEO, accesibilidad, E2E, carga, backups, observabilidad, memoria, diagramas y defensa técnica.
