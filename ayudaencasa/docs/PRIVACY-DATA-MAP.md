# Privacy data map

| Data | Classification | Public | Purpose |
|---|---|---:|---|
| Email/password hash | Restricted identity | No | Authentication/recovery |
| Session/token digests | Restricted security | No | Authentication/security |
| Display name/bio/avatar | User-controlled public | Opt-in | Marketplace profile |
| City/postal prefix | Coarse location | Opt-in | Discovery |
| Exact address | Restricted | No | Future job fulfilment only |
| Professional services/experience | Public professional | Yes when profile public | Discovery |
| Verification state | Public trust signal | Limited | Trust |
| Reviews/rating aggregate | Public marketplace | Yes | Reputation |
| Messages | Private participant content | No | Accepted-job communication |
| Audit events | Restricted operational | No | Security/accountability |

Data minimization is the default. A new public field requires an explicit product/privacy decision.
